# Human Resources Dataset Analysis

A comprehensive HR analytics project using Power BI to clean employee data, answer business questions, build interactive dashboards, and deliver actionable insights.

## Project Overview
This project aims to analyze an HR dataset to uncover insights about employee performance, satisfaction, and retention. The project is divided into 4 phases:
1. Data Cleaning & Preprocessing (Week 1)
2. Analysis Questions Phase (Week 2)
3. Dashboard Phase (Week 3)
4. Final Presentation (Week 4)
